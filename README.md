# 抄表系統

用手機相機拍錶面 → 自動辨識數字 → 人工確認 → 自動寫入 Google 試算表。

- 📍 **自訂抄表地點**：名稱、表別（電／水／瓦斯）、表號、單位、小數位數、起始讀數
- 📷 **相機自動辨識**：對準框內拍照，使用 [Tesseract.js](https://github.com/naptha/tesseract.js) 在手機上直接辨識數字（不需上傳到第三方）
- ✅ **確認後才送出**：顯示照片、辨識結果、上期讀數、本期用量；讀數倒退或用量異常（超過平均 3 倍）會提醒
- 📊 **寫入 Google 試算表**：透過 Google Apps Script，每筆一列；可選擇同時把照片存到 Google 雲端硬碟
- 📶 **離線可用**：沒網路時先存在手機，恢復連線後自動補送（以紀錄 ID 去重，不會重複寫入）
- ⬇️ 匯出 CSV、匯出／匯入地點清單（多支手機共用）

純前端網頁（PWA），不需要架伺服器，可「加入主畫面」當 App 使用。

---

## 一、建立 Google 試算表後端（約 3 分鐘）

1. 新建一個 Google 試算表。
2. 選單 **擴充功能 → Apps Script**，刪除預設內容，貼上 [`apps-script/Code.gs`](apps-script/Code.gs) 的全部內容。
3. 把第一行的 `SECRET = 'change-me'` 改成你自己的密鑰（任意字串）。
4. 右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**任何人**
5. 按「部署」並授權，複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

第一次寫入時會自動建立「抄表紀錄」工作表，欄位如下：

| 抄表時間 | 地點 | 表別 | 表號 | 本期讀數 | 上期讀數 | 用量 | 單位 | 抄表人 | 備註 | OCR辨識值 | OCR信心 | 照片 | 紀錄ID |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

> 之後如果修改了 Code.gs，要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」才會生效。

## 二、把網頁放上網路

相機功能**必須使用 https**，最簡單是用 GitHub Pages：

1. GitHub repo → **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選這個分支、資料夾選 `/ (root)`，儲存
3. 約 1 分鐘後會得到網址，例如 `https://<帳號>.github.io/001/`

（也可以放到 Netlify、Cloudflare Pages 等任何靜態網站服務。）

## 三、手機上設定

1. 用手機瀏覽器打開上面的網址，建議「加入主畫面」。
2. **設定** 頁：貼上 Apps Script 網址、填入相同的密鑰、輸入抄表人姓名 → 按「測試連線」。
3. **抄表** 頁：按「＋ 新增地點」建立所有抄表點。
4. 開始抄表：點地點 → 數字對準綠框 → 拍照 → 確認／修正數字 → 「確認送出」。

長按（電腦上按右鍵）地點可以編輯或刪除。

## 辨識小技巧

- 讓**數字列剛好填滿綠框**，越正、越清楚越好；暗處可用右上角 🔦 手電筒（Android Chrome 支援）。
- 錶面最後幾位是紅色小數字輪時，在地點設定「小數位數」，系統會自動補小數點。
- 機械字輪、印刷數字辨識效果較好；**七段顯示器（液晶數字）辨識率較低**，請務必在確認頁核對。
- 辨識不到或不準時，直接在確認頁修改數字即可，試算表會同時記錄「OCR 辨識值」方便日後比對。

## 檔案結構

```
index.html          主頁面
app.js              主程式（地點管理、相機、OCR、同步）
style.css           樣式
sw.js               Service Worker（離線快取）
manifest.json       PWA 設定
icons/icon.svg      圖示
apps-script/Code.gs Google Apps Script 後端
```

## 資料與隱私

- 地點清單與抄表紀錄存放在手機瀏覽器（localStorage），清除瀏覽器資料會一併清除，請定期用「匯出地點」備份。
- 照片只在辨識時於手機本機處理；只有勾選「上傳照片」才會傳到你自己的 Google 雲端硬碟。
