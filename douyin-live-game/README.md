# ⚔ 彈幕攻城戰 — 抖音直播互動遊戲

紅藍兩隊攻城對戰。觀眾在直播間**評論選邊、點讚出兵、送禮物召喚兵種與技能**，先攻破對方城堡的一隊獲勝。

- 直立 1080×1920 畫面，直接放進 OBS／直播伴侶當「瀏覽器來源」
- 純前端（Canvas + WebAudio），不需要圖片或音檔，也不需要安裝套件
- 每個禮物都有不同效果，大禮物有全螢幕特效、橫幅、震動、音效
- 本局戰神榜、MVP、比分累計，每局自動重開

## 玩法

| 觀眾行為 | 效果 |
|---|---|
| 評論 `1`／`紅` | 加入紅隊，戰場出現一名掛著你名字的小兵 |
| 評論 `2`／`藍` | 加入藍隊 |
| 評論 `666`／`衝`／`加油` | 你的兵進入衝鋒狀態（加速）；你的兵頭上會冒出你的評論 |
| 點讚 | 每累積 20 個讚，替你的隊伍召喚一名小兵 |
| 關注 | 獲得一名騎士 |
| 分享 | 獲得 3 名小兵 |
| 送禮 | 見下表（沒選邊的人送禮，會自動分配到人少的那隊） |

| 禮物 | 效果 |
|---|---|
| 💗 小心心 | 3 名小兵 |
| 🌹 玫瑰 | 2 名弓箭手（遠程） |
| 🎵 抖音 | 2 名騎士（高速） |
| 🎫 人氣票 | 城堡無敵護盾 8 秒 |
| 🍭 棒棒糖 | 全軍補滿血、城堡 +300 |
| 🪄 仙女棒 | 2 名法師（範圍傷害） |
| 🦆 加油鴨 | 全隊狂暴 10 秒（攻擊 ×1.6、攻速、移速提升） |
| 💊 能力藥丸 | 召喚巨人（高血量坦克） |
| 🍩 甜甜圈 | 冰凍敵方全軍 5 秒 |
| 🪞 魔法鏡 | 天降 10 道落雷 |
| 🎈 熱氣球 | 空投 12 小兵 + 3 弓箭手 + 1 戰車 |
| 🎡 嘉年華 | 巨龍降臨 + 12 顆隕石 + 全隊狂暴 15 秒 |
| 🏎️ 跑車／🚀 火箭 等 | 隱藏效果（戰車、隕石雨＋空投巨人） |
| 其他禮物 | 依抖幣價值自動對應：小兵 → 騎士 → 巨人 → 空投 → 巨龍 |

禮物數量會相乘（例如 小心心 ×10 = 30 名小兵）。每隊同時在場上限 150，超過的會排隊出兵。
每局 5 分鐘，城堡被攻破或時間到（血量比例高者勝）就結算，12 秒後自動開新局；休息時送的禮物會在下一局開場生效。

所有數值、禮物對應、關鍵字都在 [`js/config.js`](js/config.js)，改完重新整理即可。

## 快速試玩（不用開直播）

直接用瀏覽器開啟 `index.html?sim=1`，或：

```bash
cd douyin-live-game
node bridge/server.js          # 需要 Node.js 18+，不需要 npm install
```

打開 <http://localhost:3000/?sim=1>，右側會出現**模擬控制台**（隨時按 `S` 開關），可以點按鈕模擬評論、點讚、送禮；按「🤖 自動模擬」會有 30 位假觀眾一起玩。

網址參數：

| 參數 | 說明 |
|---|---|
| `?sim=1` | 開啟模擬控制台 |
| `?bots=1` | 一打開就開始自動模擬 |
| `?demo=60` | 60 秒沒有真實觀眾互動時，自動播放暖場示範；有人互動就停 |
| `?round=180` | 每局秒數 |
| `?mute=1` | 靜音 |
| `?ws=ws://127.0.0.1:8888` | 連到指定的彈幕 WebSocket（多個用逗號分隔） |

## 接上真正的抖音直播

遊戲本身只負責「收到事件 → 演出效果」，直播間的評論／禮物需要由下列其中一種方式送進來：

### 方式 A：彈幕抓取工具（最快）

使用會把直播間訊息轉成本機 WebSocket 的工具（例如 GitHub 上的 *DouyinBarrageGrab*，預設 `ws://127.0.0.1:8888`）。啟動工具、打開自己的直播間後：

```
index.html?ws=ws://127.0.0.1:8888
```

遊戲已內建該類工具的訊息格式（`{ Type: 1~8, Data: {...} }`：1 評論、2 點讚、3 進場、4 關注、5 禮物、8 分享），連擊禮物會依 `RepeatCount` 自動去重，不會重複計算。

也可以讓轉發伺服器幫你接：

```bash
node bridge/server.js --upstream ws://127.0.0.1:8888   # 需要 Node.js 22+
```

> 第三方抓取工具並非抖音官方提供，請自行評估使用風險與平台規範。

### 方式 B：抖音直播開放平台（官方）

在抖音開放平台申請「直播小玩法」後，把評論／禮物／點讚的推送 POST 到轉發伺服器：

```
POST http://你的伺服器:3000/event?token=你的密碼
```

（啟動時加 `--token 你的密碼` 防止別人亂送。）遊戲能直接讀懂開放平台的 `live_comment`／`live_gift`／`live_like`／`live_fansclub` 推送內容。開放平台的禮物是 `sec_gift_id`，請在 `config.js` 的禮物設定加上 `ids: ['你的 sec_gift_id']` 來對應；沒對應到的會依禮物價值自動給效果。正式上架需依平台規範做簽名驗證，建議在你自己的後端驗證後再轉發到 `/event`。

### 方式 C：自己的腳本

任何程式只要送出下面格式（透過 WebSocket 或 `POST /event`，可單筆或陣列）即可：

```json
{ "type": "chat",   "user": { "id": "123", "name": "小明" }, "text": "1" }
{ "type": "like",   "user": { "id": "123", "name": "小明" }, "count": 10 }
{ "type": "gift",   "user": { "id": "123", "name": "小明", "avatar": "https://..." },
  "gift": { "name": "嘉年華", "count": 1, "diamond": 3000 } }
{ "type": "follow", "user": { "id": "123", "name": "小明" } }
{ "type": "share",  "user": { "id": "123", "name": "小明" } }
```

測試範例：

```bash
curl -X POST localhost:3000/event -d '{"type":"gift","user":{"name":"土豪"},"gift":{"name":"嘉年華","count":1}}'
```

## 放進 OBS／直播伴侶

1. 新增「瀏覽器來源」，網址填 `http://localhost:3000/`（或 `file:///…/index.html?ws=…`）
2. 寬 **1080**、高 **1920**
3. 勾選「透過 OBS 控制音訊」即可把遊戲音效一起推流
4. 畫面左下角的連線狀態，連上後 4 秒會自動隱藏

## 檔案結構

```
douyin-live-game/
├── index.html          頁面與模擬控制台
├── css/style.css
├── js/config.js        ★ 禮物效果、兵種數值、關鍵字（改這裡）
├── js/game.js          遊戲引擎：戰鬥、特效、繪圖
├── js/connector.js     直播事件格式轉換與 WebSocket 連線
├── js/audio.js         即時合成音效
├── js/main.js          進入點、模擬控制台、自動模擬
└── bridge/server.js    零依賴轉發伺服器（網頁 + /ws 廣播 + POST /event + 上游轉接）
```
